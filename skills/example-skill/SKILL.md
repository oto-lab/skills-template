# Example Skill

1. State the task the skill should handle and what the agent should deliver.
2. Write a description that names the action, the inputs or subject, and the requests that should activate the skill.
3. Record the decisions that depend on this task, including any required tools or checks.
4. Try the description against a realistic request and an adjacent request that should use a different skill.
